## 🌟 项目简介

**心隙专注 (Xinxi Focus)** 是一款专为追求极致专注体验的用户打造的移动端应用。不同于传统的云端同步应用，我们信奉**本地优先 (Offline-First)** 的理念，所有数据全由你掌控。

这里没有繁琐的弹窗，没有强制的登录，只有一个为你精心打磨、如同“数字避难所”般的宁静空间。

### ✨ 核心功能

- ⏳ **沉浸式专注计时**：精心设计的动态动画，配合深色模式适配，让你瞬间进入状态。
- 🏆 **动态成就系统**：基于本地历史记录实时计算，记录你成长的每一个脚印（连续天数、专注时长、深夜努力）。
- 📊 **深度数据分析**：清晰的图表统计与历史回顾，无需网络即可随时复盘。
- 📱 **原生系统适配**：针对安卓全面屏进行的沉浸式适配（Edge-to-Edge），完美支持深色模式与系统栏同步。

### 🛡️ 隐私与安全

- **数据不过云**：所有专注记录和个人档案均存储于本地。
- **无需登录**：无需注册，开箱即用，彻底杜绝数据泄露风险。

如果你想在本地开发环境运行项目：

1. **安装依赖**
   ```bash
   npm install
   ```
2. **启动开发服务器**
   ```bash
   npm run dev
   ```

## 🛠️ 技术栈
- **Frontend**: React 19 + Vite
- **Styling**: Tailwind CSS + Motion
- **Native Bridge**: Capacitor
- **Storage**: Browser LocalStorage (Local-First)
